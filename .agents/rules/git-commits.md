# Convención de Mensajes de Commit

- **Título en modo imperativo**: Todo mensaje de commit debe redactarse en modo imperativo (ejemplos: "Añade...", "Arregla...", "Mejora...", "Actualiza...", "Elimina...").
- **Cuerpo descriptivo**: Debe explicar el **porqué** se realizó el cambio, **NO el cómo**.
- **Idioma**: Redactar siempre en **español simple**.
