# Reglas del Proyecto

## Convención de Commits de Git
- **Modo imperativo en el título**: Todo commit debe escribirse en modo imperativo (por ejemplo: "Añade...", "Arregla...", "Mejora...", "Actualiza...", "Elimina...").
- **Cuerpo del commit**: Debe explicar el **porqué** se realizó el cambio, **NO el cómo**.
- **Idioma**: Siempre en **español simple**.
